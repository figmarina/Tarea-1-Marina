# OceanHackWeek – Tarea 1

## Exploración inicial de un conjunto de datos

Este repositorio contiene la primera actividad del curso OceanHackWeek, desarrollada utilizando R y RStudio.

### Objetivo

Cargar un conjunto de datos, visualizar sus primeras observaciones y presentar una breve descripción de su contenido.

### Conjunto de datos

Se utilizó una base de datos de *Mugil curema*, que contiene 721 registros y 13 variables relacionadas con características biométricas y reproductivas de los organismos muestreados.

### Archivos

- `Datos mugil.xlsx`: conjunto de datos utilizado.
- `Tarea_1_Marina.Rmd`: notebook desarrollado en R.
- `Tarea_1_Marina.nb.html`: versión HTML del notebook con los resultados.

### Herramientas utilizadas

- R
- RStudio
- Paquete `readxl`
- R Markdown
